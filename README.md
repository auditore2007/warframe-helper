# Warframe Helper (Codex Tenno)

Помощник по Warframe для ПК. React + Electron.

Что есть (шесть разделов слева, внутри вкладки; поиск по всему - Ctrl+K):

- мир сейчас: циклы, разломы, вылазка, Баро
- ротации: Тешин на месяц вперёд, Цепь Дувири, Архонты, Ночная волна
- справочник: фреймы, оружие, компаньоны, моды, арканы, реликвии, осколки Архонта, ресурсы, звёздная карта, гайды
- торговля: цены с warframe.market, сколько в среднем стоит открыть реликвию, список на продажу (копирует WTS для чата)
- трекер мастерства по профилю, планировщик фарма, таймеры литейной, синдикаты, коллекции (кува, догмат, кода, моды кошмара)
- оверлей поверх игры, Ctrl+Shift+O. Игра должна быть в оконном без рамки, в полноэкранном не видно
- распознавание наград разлома: на экране выбора жмёшь Ctrl+Alt+R, в оверлее цены всех наград и лучшая. Текст читается tesseract'ом прямо на компе, первый раз качает языковой пакет (~15 МБ)
- калькулятор урона для стрелкового оружия
- сборки с Overframe на страницах фреймов и оружия
- график цены по сделкам на рынке (90 дней / 48 часов)
- привязка аккаунта через вход на warframe.com (можно через Steam, PlayStation, Xbox, Switch, Epic), ID подхватывается сам
- подсказка по компонентам прямо в игре: навёл курсор (или кликнул) на название детали, рядом всплывает, где её брать, цена и есть ли она у тебя
- что качать для мастерства, по профилю, от простого к сложному
- слежка за ценами: уведомление, когда кто-то продаёт дешевле заданной цены
- Баро: что сдать за дукаты, где дукаты дешевле всего, сколько стоит его товар на рынке
- цены ривенов по оружию и статам
- калькулятор: ближний бой и урон по каждой фракции
- трей, автозапуск, настройки горячих клавиш и области для скана наград

## Запуск

```bash
npm install
npm run dev     # разработка
npm run dist    # установщик и portable .exe в release/
npm test
```

## Данные

- warframestat.us - предметы, дроп, мир. Кэш лежит в `%APPDATA%\Warframe Helper\cache`, без интернета тоже работает
- картинки из WFCD `warframe-items`, тоже кэшируются
- warframe.market - цены. Прайм-части одним запросом через `/v1/tools/ducats`
- профиль Warframe - MR, вкачанные предметы, репа синдикатов. Нужен ID аккаунта, в `EE.log` его больше нет, так что вводится руками
- гайды, тиры, советы - руками в `src/data/`

Цели, части, таймеры и прочее хранятся локально.
